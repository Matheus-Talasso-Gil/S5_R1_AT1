## Identifique a função das tags

| Tag  | Função             |
| ---- | ------------------ |
| `h1` | Título principal   |
| `p`  | Parágrafo          |
| `ul` | Lista não ordenada |
| `ol` | Lista ordenada     |
| `li` | Item da lista      |
| `a`  | Hiperlink          |
| `br` | Quebra de linha    |
| `hr` | Linha horizontal   |
