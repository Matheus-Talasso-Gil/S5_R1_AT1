# Dicionário de HTML: Textos, Listas e Links

Conceitos importantes para organizar o conteúdo das páginas da S5.

## Estrutura do HTML

| Termo | Significado |
| --- | --- |
| **HTML** | Linguagem usada para estruturar uma página web. |
| **Tag** | Marcação que identifica um elemento, como `<p>`. |
| **Atributo** | Informação que configura um elemento, como `href`. |
| **`head`** | Reúne informações sobre a página. |
| **`title`** | Define o título da aba do navegador. |
| **`body`** | Contém o conteúdo apresentado na página. |

## Textos e listas

| Termo | Significado |
| --- | --- |
| **`h1`** | Título principal da página. |
| **`h2`** | Título de uma seção. |
| **`p`** | Parágrafo de texto. |
| **`ul`** | Lista não ordenada, como os hobbies e serviços. |
| **`ol`** | Lista ordenada, como as etapas de atendimento. |
| **`li`** | Item de uma lista. |
| **`br`** | Quebra de linha; citado no enunciado. |
| **`hr`** | Separação temática, geralmente exibida como linha horizontal; citado no enunciado. |

## Links

| Termo | Significado |
| --- | --- |
| **`a`** | Elemento usado para criar um link. |
| **`href`** | Indica o endereço de destino do link. |
| **`target="_blank"`** | Abre o destino normalmente em uma nova aba. |

## Exemplo

```html
<a href="https://github.com/Matheus-Talasso-Gil" target="_blank">
    Acesse meu GitHub
</a>
```

Nesse exemplo, `href` indica o destino, e `target="_blank"` abre o link normalmente em outra aba. O texto entre as tags é a parte clicável.
